## بنود لم تُغيَّر (عن قصد، ورثت من الفرعين الأصليين)
- حد أقصى لعدد الجلسات المتزامنة: قرار منتج مش عيب أمني، و`logout-all-devices` موجودة.
- طلبات Paymob المعلّقة: الـ sweeper موجود وشغّال.
- الفحص البصري على شاشات 320px: محتاج اختبار يدوي حقيقي.
- كثافة التعليقات التاريخية: تفضيل أسلوبي، والتعليقات دي بتساعد المراجعة.

## ملاحظة
شغّل `npm ci && npm run ci` (أو `npm run ci:report`) قبل النشر للتأكد من نجاح
lint وtypecheck وXSS audit وكل الاختبارات (بما فيها اختبار التكامل الجديد
القديم المُسترجَع) على بيئتك.
