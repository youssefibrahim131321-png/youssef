# تطوير متجر يوسف — V6

## الرؤية الجديدة

تم تحويل الواجهة إلى هوية أكثر فخامة تعتمد على **الأبيض والكحلي** مع درجات ملكية زرقاء ولمسات ذهبية صغيرة، بدل الاعتماد على المؤثرات وحدها. الهدف هو رفع الثقة، جعل المنتجات أكثر وضوحًا، وإعطاء لوحة التحكم إحساس مركز عمليات احترافي.

## المتجر

تمت إضافة طبقة بصرية بيضاء وكحلية فوق التصميم الحالي، تشمل خلفيات هادئة، هيدر زجاجي، أزرارًا كحلية متدرجة، بطاقات منتجات أكثر نظافة، وظلالًا خفيفة وتباينًا أعلى. تم الحفاظ على RTL والحركات السابقة مع احترام `prefers-reduced-motion`.

## مركز العمليات في لوحة التحكم

أضيفت منطقة قيادة أعلى صفحة النظرة العامة بعنوان «مركز قيادة يوسف» مع وصف تشغيلي وإجراءات مباشرة. تشمل الإجراءات تشغيل الفحص الذكي، إضافة منتج، إنشاء نسخة احتياطية، وتصدير الطلبات.

تمت إضافة مؤشرات تشغيلية تعرض الطلبات التي تحتاج متابعة، المخزون المنخفض، إيرادات اليوم، ومتوسط قيمة الطلب. كما تظهر بطاقات تنبيه ذكية تقود المستخدم مباشرة إلى صفحة الطلبات أو المخزون، وتعرض حالة مستقرة عندما لا توجد تنبيهات.

زر «تشغيل الفحص الذكي» يفحص صحة الخدمة وصحة Paymob من داخل لوحة التحكم ويعرض النتيجة للمستخدم مع وقت آخر فحص. هذا يكمّل أمر `npm run automation:health` الخارجي المناسب لـ cron وCI.

## الأمان والجودة

كل عناصر مركز العمليات التي تعتمد على قيم متغيرة تُبنى عبر DOM آمن، ولم يتم إدخال قيم إدارية جديدة مباشرة في `innerHTML`. تم تشغيل فحص XSS، lint، typecheck، والاختبارات الكاملة بعد التعديل.

## ملاحظات التشغيل

يتطلب التشغيل المحلي دون PostgreSQL استخدام `ALLOW_MEMORY_DB=1` للتطوير فقط. لا ينبغي استخدام قاعدة الذاكرة في الإنتاج. يجب ضبط `DATABASE_URL` و`SITE_URL` و`ALLOWED_HOSTS` وVolumes دائمة للبيانات والصور قبل النشر الحقيقي.
