# تقسيم الواجهة لموديولات ES

`public/admin.js` (955 سطر) و `public/storefront.js` (1064 سطر) اتقسموا لموديولات
ES. نفس المنطق بالحرف، بس كل ملف بقى له مسؤولية واحدة، و `no-undef` بقى شغّال
في الـ lint (قبل كده كان مقفول لأن كل حاجة كانت globals).

## لوحة التحكم — `public/js/admin/`
| ملف | مسؤوليته |
|---|---|
| `core.js` | أدوات مشتركة: `$`، `api()`، المودالات، التوستات، التهريب |
| `labels.js` | ثوابت التسميات والحالات والأيقونات |
| `widgets.js` | الرسوم البيانية، الدونات، عدّادات الـ KPI، شرائح الحالة |
| `overview.js` / `orders.js` / `products.js` / `inventory.js` / `coupons.js` / `users.js` / `reviews.js` / `activity.js` / `notify.js` / `settings.js` | كل قسم في اللوحة لوحده |
| `nav.js` | التنقل بين الأقسام |
| `main.js` | نقطة الدخول: بتربط كل الموديولات وتشغّل الـ boot |

## المتجر — `public/js/store/`
| ملف | مسؤوليته |
|---|---|
| `core.js` | `$`، أدوات الـ UI، شريط أخطاء الشبكة، التوست |
| `state.js` | الحالة المشتركة (اليوزر، المنتجات، السلة، الإعدادات) + دوال `set*` |
| `product-links.js` | روابط/سلاج المنتج وتحميل كل الصفحات |
| `effects.js` | شاشة التحميل، شريط السكرول، الجزيئات، الظهور التدريجي، العدّادات |
| `auth.js` / `wishlist.js` / `notifications.js` | الحساب والمفضّلة والإشعارات |
| `catalog.js` / `product-modal.js` / `cart.js` | العرض والمنتج والسلة |
| `interactions.js` / `nav.js` | ربط الضغطات والفلاتر والبحث + القائمة |
| `main.js` | نقطة الدخول |

## ملاحظات مهمة
- الـ ES modules ما بتسمحش بإعادة تعيين متغيّر مستورد، فأي تغيير في حالة المتجر
  بيمرّ على `setCurrentUser` / `setProducts` / `setWishlistIds` … إلخ.
- ربط الأحداث اتجمّع في دوال `wire*()` بيناديها `main.js` بترتيب واضح — ده اللي
  منع الاعتماد الدائري بين الموديولات.
- **إصلاح**: `pruneMissingCartItems` في المتجر كانت بتنادي `toast()` (دالة لوحة
  التحكم) بدل `showToast()`، فالتنبيه كان بيرمي خطأ. اتصلحت.
- ملفات لوحة التحكم بتتقدّم من السيرفر ورا نفس حماية اللوحة
  (`/js/admin/:file` + `requireAdminPanel` + قائمة أسماء صريحة تمنع path
  traversal)، ومش داخلة في كاش الـ service worker. ملفات المتجر عامة ومتكاشة.
- `tools/xss-audit.js` بقى بيفحص كل ملفات الموديولات، وبيجمع خرائط الثوابت
  الآمنة من كل الملفات (لأن `PAYMENT_ICONS` بقت في `labels.js`).

## تقسيم v7 (تقليل الملفات العملاقة)

### مسارات الـ Express — `lib/routes/`
| الملف | المحتوى |
|---|---|
| `admin-panel-routes.js` | صفحات لوحة التحكم الثابتة والمحمية |
| `seo-routes.js` | robots.txt وخريطة الموقع |
| `public-api-routes.js` | نقاط عامة (منتجات، إعدادات، تقييمات للقراءة) |
| `auth-routes.js` | تسجيل/دخول/خروج، تفعيل البريد، استعادة كلمة المرور، 2FA |
| `shop-routes.js` | السلة، الكوبونات، إنشاء الطلبات، طلبات العميل |
| `notification-routes.js` | الإشعارات واشتراكات web push |
| `admin-order-routes.js` | إدارة الطلبات والتصدير |
| `admin-catalog-routes.js` | منتجات وأقسام وكوبونات (كتابة) |
| `admin-users-routes.js` | إدارة المستخدمين والصلاحيات |
| `upload-routes.js` | رفع صور المنتجات وإيصالات الدفع |
| `invoice-routes.js` | فواتير الطلبات |

كل ملف بيصدّر `register...Routes(app, deps)` والاعتماديات بتتحقن من `server.js`،
فمفيش استيراد دائري ومفيش حالة عامة مخفية.
