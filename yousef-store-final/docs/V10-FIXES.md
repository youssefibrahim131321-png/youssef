# V10 — إصلاحات إضافية وتطوير الحركة

## الإصلاحات

- تحويل تعليم الإشعارات غير المقروءة إلى طلب جماعي واحد عبر `/api/notifications/read-all` بدل طلب منفصل لكل إشعار.
- إضافة `noindex` للصفحات الخاصة بالحساب والاستعادة والتحقق وتسجيل دخول الإدارة.
- توحيد وصف صفحة حالة الطلب وإضافة Open Graph أساسي لها.
- الإبقاء على مزامنة السلة مع المنتجات والمخزون الحالي قبل العرض والحساب، مع تنظيف العناصر المحذوفة أو الكميات غير الصالحة.

## التصميم والحركة

- إضافة طبقة ظهور تدريجي للبطاقات ومحتوى البطل.
- تحسين حركة صور المنتجات عند التحويم.
- إضافة تفاعلات ضغط ناعمة للأزرار والأزرار التفاعلية.
- إضافة حركة خفيفة لبطاقات مركز الإدارة.
- احترام `prefers-reduced-motion` وإيقاف الحركات عند طلب المستخدم.

## التحقق

- 94/94 اختبارًا ناجحًا.
- lint ناجح.
- فحص الصياغة/typecheck ناجح على 136 ملفًا.
- تم التحقق من وجود endpoint الإشعارات الجماعي ووسوم noindex في الصفحات الخاصة.

## تشغيل الإنتاج

يجب ضبط مفاتيح الإنتاج، خصوصًا `DATABASE_URL` و`SITE_URL` و`ALLOWED_HOSTS` و`TOTP_ENCRYPTION_KEY`، واستخدام تخزين دائم وقواعد نسخ احتياطي خارجية مناسبة.
